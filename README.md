# UML 绘图工具

这是一个可离线使用的绘图工具。支持活动图、泳道图、序列图、实体关系图、构件图、部署图、类图和用例图。图稿保存为可继续编辑的 JSON，也可以导出为 PNG 图片。

## 启动与新建

双击 `一键启动.bat`，或用 Edge、Chrome 打开 `index.html`；无需安装依赖或启动服务。

1. 在左侧选择**绘图模式**。每种模式只显示适用的插入形状。
2. 可从**基础模板**选择空白画布、活动图或泳道图，也可从**教材图稿**选择内置的 15 张设计分析图。选择图稿会载入其内容，若当前修改尚未导出，请先保存 JSON。
3. 点击形状按钮插入图元，拖动到合适位置。选中图元后可拖动右下角控制块改变大小，或在左侧输入宽度、高度；在“选中内容”中修改文字。双击节点或泳道标题可直接定位到文字输入框。
4. 点击“连线”，依次点击起点节点和终点节点。再次点击“连线”或按 Esc 退出连线状态。选择连线后可以编辑文字、走向、箭头和线型。
5. 修改图标题和画布尺寸；也可以拖动画布四边的蓝色短线调整尺寸。

不同模式可插入的形状如下：

| 模式 | 形状 |
| --- | --- |
| 活动图、泳道图 | 活动框、判断、开始、结束 |
| 序列图 | 参与者、生命线、状态框、执行长条、回接圆圈、外部触发、文字 |
| 实体关系图 | 实体、关系、属性、文字 |
| 构件图 | 构件、分栏类框、接口圆圈、文字 |
| 部署图 | 部署节点、软件文件夹、构件、文字 |
| 类图 | 分栏类框、接口圆圈、文字 |
| 用例图 | 参与者小人、用例椭圆、系统边界、文字 |

序列图的状态框表示状态，窄长的执行条表示一次执行的起止，虚线是生命线。类框的文字用独立一行 `--` 分隔类名、属性和操作，例如 `照片\n--\nid: UUID\n--\n保存()`；在编辑框中要输入实际换行，不是输入字符 `\n`。

## 选择、拖动与快捷键

- **Ctrl + 点击节点**：将节点加入多选或从多选中移除；随后拖动其中一个已选节点，可一起移动。Shift + 点击节点也可增减多选。画布空白处拖出选择框，也能选中多个节点。
- **Shift + 拖动橙色连线端点**：约束的是**连线本身的方向**，使被拖动的线段相对另一端保持水平、垂直或 45° 对角方向（共八向）。不按 Shift 时可自由调整连接位置。连线的起点和终点仍属于原来的节点。若是折线，约束作用于靠近被拖端点的那一段。
- **Shift + 拖动节点**：限制节点整体移动为水平或垂直方向；这与连线端点的八向规则不同。
- **选中连线**：拖动两端橙色圆点调整连接位置；拖动中间的蓝色圆点调整拐点；直接拖动线段可移动该段。左侧可增加或删除拐点，修改起终点连接位置、直线/直角折线/右侧回路线、实心箭头/空心箭头/无箭头及实线/虚线。连线文字可在画布上拖动。
- **Ctrl+C、Ctrl+V**：复制、粘贴选中的节点。多选时复制多个节点；连线不会一起复制。
- **Ctrl+Z、Ctrl+Y**：撤销、重做。**Delete** 删除选中内容；**Esc** 退出连线状态。

泳道图可以新增泳道，拖动分隔线调宽；点击泳道标题可修改名称和颜色。颜色随 JSON 保存，也用于 PNG 导出。

## 保存和导出

工具会尝试在当前浏览器中自动保存。点击“保存到浏览器”或“读取浏览器保存”可手动操作。浏览器存储可能因清理数据或换浏览器而消失；需要长期保留或交换图稿时，请点击**导出图稿**保存 `.json`。重新编辑时点击**导入图稿**并选择该 JSON 文件。**导出 PNG 图片**生成画布宽、高各 2 倍的图片，不包含编辑控制点。

## JSON 导入要求

导入的是**单张图的 `.json` 文件**，不能选择包含多张图的目录清单（例如 `图稿目录.json`）或图片文件。文件须为合法 JSON，大小不超过 **5 MB**。支持 UTF-8、带 BOM 的 UTF-8，以及带 BOM 的 UTF-16 LE/BE。导入失败时左侧状态栏和弹窗会显示原因；请先检查文件格式、大小及是否选错了清单文件。

本工具导出的图稿使用 `version: 2` 的 `nodes`/`edges` 结构。最小示例如下（坐标 `x`、`y` 是节点左上角，`w`、`h` 是宽高）：

```json
{
  "version": 2,
  "mode": "usecase",
  "title": "示例用例图",
  "width": 1200,
  "height": 900,
  "nodes": [
    {"id": "actor-1", "type": "actor", "x": 100, "y": 200, "w": 90, "h": 180, "text": "用户"},
    {"id": "usecase-1", "type": "usecase", "x": 500, "y": 220, "w": 200, "h": 100, "text": "查看照片"}
  ],
  "edges": [
    {"id": "edge-1", "from": "actor-1", "to": "usecase-1", "label": "", "route": "straight", "arrow": "none", "dashed": false}
  ]
}
```

`mode` 可取 `activity`、`swimlane`、`sequence`、`er`、`component`、`deployment`、`classdiagram`、`usecase`。`nodes` 必须是数组，节点 `id` 不可重复；`type` 必须是工具支持的图元类型，位置和尺寸必须是数字。`edges` 必须是数组，`from`、`to` 必须引用已存在的节点 ID。连线可选用 `route`（`straight`、`orthogonal`、`right`）、`arrow`（`solid`、`open`、`none`）、`dashed`（布尔值）、`via`（拐点坐标数组）及 `anchors`（两端相对节点的连接位置）。画布宽度支持 400–4000，高度支持 400–6000；单图最多 1000 个节点、3000 条连线。

还可导入两类已有文件：

- 旧版 G01–G11 教材活动图/泳道图 JSON：`nodes` 是按 ID 建立的对象，使用中心坐标、`kind`、字符串泳道等；导入时自动转换。请选具体的 Gxx 图稿。
- `schema: "campus-diagram/v1"` 且 `diagramType: "sequence"` 的序列图（例如 `序列图修改预览/G10.json`）：由 `elements` 中的矩形、文字、线条转换为可编辑节点和连线。其他 `campus-diagram/v1` 图种目前不支持。

成功导入旧格式后，再用“导出图稿”保存，即可得到本工具的 JSON 格式。重要图稿建议另存副本。
